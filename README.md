# CoreFix | BELMO LABS

Arabic and English computer repair simulator with 64 modeled faults, an interactive hardware workbench and practical diagnostic tools.

محاكي صيانة كمبيوتر بالعربية والإنجليزية: 64 عطلًا، ورشة تفاعلية وأدوات تشخيص وتقييم.

## Run

Open `index.html` directly in a modern browser. No installation or build is required.

## GitHub Pages

In Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.

## Included

- 64 faults in 10 categories
- Desktop, laptop and workstation teaching profiles
- Four difficulty levels and individual-fault practice
- Inspection, multimeter, thermal view, POST diagnostics, UEFI and simulated terminal
- Repair prerequisites, scoring, explanations and local progress

All readings and repairs are simulated. This is a training application, not an accredited certification or a tool that scans the actual device.
